## 백업 — 3번 이전에 반드시

1. **관리자 → 주문 관리 → 내려받기 → `전체 항목`** (회원·상품도 같은 자리)
2. **Supabase → Table Editor → 표 선택 → Export → Download as CSV**
   받을 표: `orders` `order_items` `order_status_history` `payment_logs`
   `point_transactions` `profiles` `products` `reviews` `inquiries`
3. **Supabase → Database → Backups** (유료 플랜이면 시점 복구 가능. 시각을 적어 두세요)

> **`delete` 는 되돌릴 수 없습니다.** Supabase 대시보드에 실행 취소가 없습니다.
